# Black Shawarma

Одностраничный сайт небольшой шаурмичной на React и Vite. Дизайн адаптирован для телефонов и компьютеров. В проекте есть главный экран, меню, история места, часы работы и контакты.

## Запуск для изучения

1. Установите Node.js (рекомендуется актуальная LTS-версия).
2. Откройте терминал в папке `app`.
3. Выполните `npm install` один раз для установки зависимостей.
4. Выполните `npm run dev`.
5. Откройте адрес, который появится в терминале (обычно `http://localhost:5173`).

Vite обновляет страницу после сохранения изменений. Главный экран и данные меню находятся в `app/src/main.jsx`, оформление — в `app/src/style.css`.

## Сборка проекта

В папке `app` выполните `npm run build`. Готовые статические файлы появятся в `app/dist`. Чтобы посмотреть собранную версию локально, выполните `npm run preview`.

## Docker

Из корня проекта выполните `docker compose up --build`. Сайт будет доступен на `http://localhost:8089`. Для завершения нажмите `Ctrl+C`; чтобы остановить контейнер в фоне, используйте `docker compose down`.

## Перед публикацией

Замените демонстрационные адрес, телефон и цены на реальные. Фото загружаются с Unsplash, шрифт — Google Fonts; для полностью автономного размещения сохраните изображения и шрифты в проекте локально.
